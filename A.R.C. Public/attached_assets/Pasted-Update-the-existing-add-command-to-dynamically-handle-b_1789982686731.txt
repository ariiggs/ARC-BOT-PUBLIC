   - Check the SQLite database to see if `slot_number` is already occupied. If it is, add to `error_entries` (Reason: Slot Taken).
   - If everything is correct, append a dictionary with the extracted data to `valid_entries`.

4. **Interactive UI View (discord.ui):**

     - Button 1: ✅ Confirm (Style: Success)
